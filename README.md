# 🏠 Smart Fridge Dashboard

A comprehensive smart home dashboard with FastAPI backend and modern UI. Monitor your Samsung washing machine, manage tasks, calendar events, weather, news, and more.

![Python](https://img.shields.io/badge/python-3.11+-green)
![FastAPI](https://img.shields.io/badge/FastAPI-0.104.1-teal)
![Render](https://img.shields.io/badge/Render-Ready-purple)

## ✨ Features

- 🧺 **SmartThings Washing Machine Integration** - Real-time status with vibrating icon
- 📋 **Google Tasks** - Create and manage tasks with local fallback
- 📅 **Google Calendar** - Event management with local backup
- ⏰ **Scheduled Tasks** - Auto-create tasks (including daily 3 PM check-in)
- 🌤️ **Weather** - Real-time weather with OpenWeatherMap
- ✈️ **Live ATC** - Aircraft tracking in your area
- 📰 **News** - Multi-source news aggregation
- 🎬 **YouTube Search** - Search and play videos
- 🛒 **Grocery List** - Categorized grocery management
- 🖥️ **System Status** - CPU, memory, disk monitoring
